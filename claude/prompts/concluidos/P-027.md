## Contexto para o Claude Code

Este é o service mais crítico do Épico 3.1. Implementa a RN-036 completa:

**RN-036 — fluxo ao confirmar lote:**
1. Criar registro `LoteCompra`
2. Para cada item do lote:
   - Buscar insumo (lançar erro se não encontrado ou não pertence ao usuário)
   - Recalcular `custoUnitario = precoTotalPago / quantidadeComprada`
   - Adicionar `quantidadeComprada` ao `estoqueAtual` do insumo
   - Registrar `MovimentacaoInsumo`: tipo=ENTRADA, motivo=COMPRA, referenciaId=loteId, referenciaTipo=LOTE_COMPRA
3. Retornar `ImpactoAgregadoResponse` com os insumos atualizados e seus custos anteriores/novos

**Cenário BDD (Cenário 79):**
```gherkin
Dado que a artesã confirma lote com:
  - "Papel Couché 250g": 500 unidades, R$ 250,00
  - "Cola Branca 1L": 3 unidades, R$ 45,00
Então:
  - custoUnitario de "Papel Couché" → R$ 0,50
  - custoUnitario de "Cola Branca" → R$ 15,00
  - estoques atualizados
  - 2 movimentações ENTRADA/COMPRA vinculadas ao mesmo loteId
  - ImpactoAgregadoResponse listando os dois insumos com custos anterior/novo
```

```java
@Service
@Transactional
public class LoteCompraService {

    public ImpactoAgregadoResponse registrarLote(RegistrarLoteCompraRequest request, UUID usuarioId);
}
```

### Lógica completa do `registrarLote`:

```
1. Criar LoteCompra:
   - usuario = buscar Usuario por usuarioId
   - dataCompra = request.getDataCompra() != null ? request.getDataCompra() : LocalDateTime.now()
   - salvar loteCompra → obter loteId

2. Para cada ItemLoteCompraRequest no request.getItens():
   a. Buscar Insumo por item.getInsumoId() e usuarioId
      → lançar ResourceNotFoundException se não encontrado
   b. Guardar custoUnitarioAnterior = insumo.getCustoUnitario()
   c. Calcular novo custo: novoCusto = item.getPrecoTotalPago() / item.getQuantidadeComprada()
      → usar BigDecimal.divide com escala 6 e RoundingMode.HALF_UP
   d. Atualizar insumo:
      - insumo.setCustoUnitario(novoCusto)
      - insumo.setEstoqueAtual(insumo.getEstoqueAtual().add(item.getQuantidadeComprada()))
   e. Salvar insumo
   f. Criar MovimentacaoInsumo:
      - insumo = insumo
      - tipo = ENTRADA
      - motivo = COMPRA
      - quantidade = item.getQuantidadeComprada()
      - observacao = null
      - referenciaId = loteId
      - referenciaTipo = LOTE_COMPRA
      - estornada = false
   g. Salvar movimentação
   h. Adicionar InsumoImpactoResponse à lista de resultado

3. Montar e retornar ImpactoAgregadoResponse:
   - loteId = loteCompra.getId()
   - dataCompra = loteCompra.getDataCompra()
   - insumosAtualizados = lista montada no passo 2h
   - produtosAfetados = lista vazia (placeholder para Épico 4)
```

### Atenção à divisão BigDecimal:
```java
BigDecimal novoCusto = item.getPrecoTotalPago()
    .divide(item.getQuantidadeComprada(), 6, RoundingMode.HALF_UP);
```
Nunca usar `.divide()` sem escala — lança `ArithmeticException` em dízimas periódicas.
