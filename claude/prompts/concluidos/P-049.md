### Métodos obrigatórios:

```java
@Component
public class ProducaoMapper {

    // Producao → ProducaoResponse (listagem)
    public ProducaoResponse toResponse(Producao producao);

    // Producao + insumos consumidos → ProducaoDetalheResponse
    public ProducaoDetalheResponse toDetalheResponse(
        Producao producao,
        List<ProducaoInsumoConsumido> insumosConsumidos
    );

    // ProducaoInsumoConsumido → InsumoConsumidoResponse
    public InsumoConsumidoResponse toInsumoConsumidoResponse(ProducaoInsumoConsumido consumido);
}
```

### Regras de mapeamento:

- `toResponse`: mapeia `produto.getNome()` → `nomeProduto`, `produto.getTipo()` → `tipoProduto`
- `toInsumoConsumidoResponse`:
  - `estoqueAntes`: não disponível no mapper — setar `null` (o service calcula antes de persistir e pode ignorar por ora)
  - `estoqueInsuficiente`: setar `false` por padrão no mapper (o service calcula antes de lançar)
- `toDetalheResponse`: mapeia a lista de `ProducaoInsumoConsumido` usando `toInsumoConsumidoResponse`

Compile ao final:
```bash
./mvnw compile -q
```
