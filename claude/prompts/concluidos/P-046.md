### 2. `src/services/clienteService.ts` (novo arquivo)

```ts
import api from './api';
import type { ClienteRequest, ClienteResponse } from '../types/cliente';
import type { PageResponse } from '../types/insumo';

export const clienteService = {
  listar: async (page: number, size = 20, nome?: string): Promise<PageResponse<ClienteResponse>> => {
    const params: Record<string, any> = { page, size, sort: 'nome' };
    if (nome) params.nome = nome;
    const response = await api.get('/clientes', { params });
    return response.data;
  },

  buscarPorId: async (id: string): Promise<ClienteResponse> => {
    const response = await api.get(`/clientes/${id}`);
    return response.data;
  },

  cadastrar: async (data: ClienteRequest): Promise<ClienteResponse> => {
    const response = await api.post('/clientes', data);
    return response.data;
  },

  editar: async (id: string, data: ClienteRequest): Promise<ClienteResponse> => {
    const response = await api.put(`/clientes/${id}`, data);
    return response.data;
  },

  inativar: async (id: string): Promise<void> => {
    await api.delete(`/clientes/${id}`);
  },
};
```

### 3. Conectar `ClientesPage`:

**Listagem:**
- Ao montar: `clienteService.listar(0)` → primeiros 20
- Campo de busca por nome: ao alterar, reseta `page=0` e `clientes=[]` (RN-034)
- "Carregar mais": acumula resultados
- Botão "Carregar mais" some quando `hasNext=false`

**Cadastro / Edição:**
- Se a tela usa modal ou rota separada para formulário, conecte ao `cadastrar` e `editar`
- Sucesso: toast + atualiza lista
- Erro `400` com `fieldErrors`: exibe por campo
- Erro genérico: exibe `error.response.data.message`

**Inativação:**
- Menu ⋮ ou botão "Inativar": chama `clienteService.inativar(id)`
- Sucesso: remove da lista local
- Modal de confirmação antes de inativar (se já existir na tela)

**Após conectar, compile e corrija todos os erros de TypeScript antes de commitar:**
