## Contexto para o Claude Code

O `FichaTecnicaService` é responsável por:
1. Salvar os itens da ficha técnica de um produto (substituindo os anteriores)
2. Recalcular o `precoCusto` do produto somando `quantidade × custoUnitario` de cada componente

Este service será chamado pelo `ProdutoService` sempre que um produto for criado ou editado com ficha técnica.

```java
@Service
@Transactional
public class FichaTecnicaService {

    // Salva (ou substitui) a ficha técnica de um produto e recalcula precoCusto
    public BigDecimal salvarFichaTecnica(Produto produto, List<FichaTecnicaItemRequest> itens, UUID usuarioId);

    // Recalcula precoCusto sem alterar os itens (usado quando custoUnitario de insumo muda)
    public BigDecimal recalcularPrecoCusto(UUID produtoId);
}
```

### Lógica de `salvarFichaTecnica`:

```
1. Deletar itens existentes: fichaTecnicaItemRepository.deleteByProdutoId(produto.getId())

2. Para cada FichaTecnicaItemRequest:
   a. Validar que exatamente um de insumoId ou produtoBaseId está preenchido
      → lançar BusinessException se ambos nulos ou ambos preenchidos
   b. Se insumoId preenchido:
      → buscar Insumo por insumoId e usuarioId (ResourceNotFoundException se não encontrado)
      → criar FichaTecnicaItem com insumo = insumo, produtoBase = null
   c. Se produtoBaseId preenchido:
      → buscar Produto por produtoBaseId e usuarioId
      → validar que tipo == PRODUTO_BASE (BusinessException se não for)
      → criar FichaTecnicaItem com produtoBase = produto, insumo = null
   d. Setar quantidade e produto dono
   e. Salvar item

3. Calcular precoCusto:
   BigDecimal precoCusto = itens salvos
       .stream()
       .map(item -> {
           BigDecimal custo = item.getInsumo() != null
               ? item.getInsumo().getCustoUnitario()
               : item.getProdutoBase().getPrecoCusto();
           return item.getQuantidade().multiply(custo);
       })
       .reduce(BigDecimal.ZERO, BigDecimal::add);

4. Retornar precoCusto calculado (quem chama seta no produto e salva)
```

### Lógica de `recalcularPrecoCusto`:

```
1. Buscar todos os FichaTecnicaItem do produto
2. Somar quantidade × custoUnitario de cada componente
3. Retornar o total
```

Compile ao final:
```bash
./mvnw compile -q
```
