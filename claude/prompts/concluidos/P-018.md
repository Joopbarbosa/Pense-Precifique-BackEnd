## Contexto para o Claude Code

**Regras de negócio aplicáveis:**
- **Unicidade:** `nome + marca + usuario_id` — ao cadastrar ou editar, verificar se já existe outro insumo com a mesma combinação para o mesmo usuário. Se existir, lançar exceção com mensagem "Já existe um insumo com este nome e marca."
- **Soft delete:** inativar via `deletedAt = LocalDateTime.now()` — nunca `repository.delete()`
- **RN-034:** listagem paginada, 20 itens por página

### Métodos obrigatórios:

```java
@Service
@Transactional
public class InsumoService {

    // Listar insumos ativos do usuário (paginado, 20 por página)
    public Page<InsumoResponse> listar(UUID usuarioId, Pageable pageable);

    // Buscar por id (lança ResourceNotFoundException se não encontrado ou não pertence ao usuário)
    public InsumoResponse buscarPorId(UUID id, UUID usuarioId);

    // Cadastrar novo insumo
    public InsumoResponse cadastrar(InsumoRequest request, UUID usuarioId);

    // Editar insumo existente
    public InsumoResponse editar(UUID id, InsumoRequest request, UUID usuarioId);

    // Inativar (soft delete: seta deletedAt)
    public void inativar(UUID id, UUID usuarioId);
}
```

### Regra de unicidade (aplicar em `cadastrar` e `editar`):

```java
// No cadastrar:
if (insumoRepository.existsByNomeAndMarcaAndUsuarioIdAndDeletedAtIsNull(
        request.getNome(), request.getMarca(), usuarioId)) {
    throw new BusinessException("Já existe um insumo com este nome e marca.");
}

// No editar (excluindo o próprio registro):
if (insumoRepository.existsByNomeAndMarcaAndUsuarioIdAndIdNotAndDeletedAtIsNull(
        request.getNome(), request.getMarca(), usuarioId, id)) {
    throw new BusinessException("Já existe um insumo com este nome e marca.");
}
```

### Exceções:
- `ResourceNotFoundException` (já existente no projeto — verifique antes de criar)
- `BusinessException` (já existente no projeto — verifique antes de criar; se não existir, crie em `exception/`)
