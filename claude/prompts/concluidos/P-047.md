## Prompt

Cole este prompt no Claude Code:

---

Crie as entidades JPA e repositories para `Producao` e `ProducaoInsumoConsumido`.

**Leia o CLAUDE.md e o arquivo `src/main/resources/db/migration/V1__initial_schema.sql` antes de começar — confirme os nomes exatos das colunas e da tabela (`producao_insumos_consumidos`) antes de mapear qualquer campo. Use `@Column(name=...)` explicitamente em todos os campos.**

### 1. Enum: `StatusProducao` (em `domain/enums/`)

```java
public enum StatusProducao { ATIVA, CANCELADA }
```

### 2. Entity: `Producao` (em `domain/entity/`)

Campos:
- `id` UUID PK
- `usuario` → `@ManyToOne(fetch = LAZY)` para `Usuario`
- `produto` → `@ManyToOne(fetch = LAZY)` para `Produto`
- `numero` Integer (gerado pelo banco via SERIAL — não usar `@GeneratedValue`, deixar o banco controlar)
- `quantidade` BigDecimal NOT NULL
- `dataProducao` LocalDateTime → default `LocalDateTime.now()` no `@PrePersist`
- `status` → `StatusProducao` (`@Enumerated(EnumType.STRING)`) default ATIVA
- `observacaoCancelamento` String nullable
- `dataCancelamento` LocalDateTime nullable
- `createdAt` LocalDateTime → `@CreationTimestamp`
- `updatedAt` LocalDateTime → `@UpdateTimestamp`

### 3. Entity: `ProducaoInsumoConsumido` (em `domain/entity/`)

Campos:
- `id` UUID PK
- `producao` → `@ManyToOne(fetch = LAZY)` para `Producao`
- `insumo` → `@ManyToOne(fetch = LAZY)` para `Insumo`
- `quantidade` BigDecimal NOT NULL

Sem `createdAt` nem `updatedAt` — registro imutável.

### 4. Repositories

```java
// ProducaoRepository
public interface ProducaoRepository extends JpaRepository<Producao, UUID> {
    Page<Producao> findByUsuarioIdOrderByDataProducaoDesc(UUID usuarioId, Pageable pageable);
    Optional<Producao> findByIdAndUsuarioId(UUID id, UUID usuarioId);
    Optional<Producao> findByNumeroAndUsuarioId(Integer numero, UUID usuarioId);
}

// ProducaoInsumoConsumidoRepository
public interface ProducaoInsumoConsumidoRepository extends JpaRepository<ProducaoInsumoConsumido, UUID> {
    List<ProducaoInsumoConsumido> findByProducaoId(UUID producaoId);
}
```

```bash
./mvnw compile -q
```
