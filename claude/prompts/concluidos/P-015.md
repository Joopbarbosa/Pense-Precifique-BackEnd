## Prompt

Cole este prompt no Claude Code:

---

Crie as entidades JPA e repositories para `Insumo` e `MovimentacaoInsumo` no backend Spring Boot.

**Convenções do projeto (leia o CLAUDE.md antes de começar):**
- UUID como PK (`@GeneratedValue` com `UUID.randomUUID()`)
- Soft delete via `deleted_at` (não usar `repository.delete()`)
- snake_case no banco, camelCase no Java
- Pacote base: `com.penseprecifique.api`

### 1. Enums (em `domain/enums/`)

Crie dois enums se ainda não existirem:

```java
// TipoMovimentacaoInsumo.java
public enum TipoMovimentacaoInsumo { ENTRADA, SAIDA }

// MotivoMovimentacaoInsumo.java
public enum MotivoMovimentacaoInsumo {
    COMPRA, BAIXA_MANUAL, PRODUCAO, ORCAMENTO, ESTORNO_PRODUCAO
}

// ReferenciaMovimentacaoTipo.java
public enum ReferenciaMovimentacaoTipo {
    PRODUCAO, ORCAMENTO, LOTE_COMPRA
}
```

### 2. Entity: `Insumo` (em `domain/entity/`)

Campos obrigatórios:
- `id` UUID PK
- `usuario` → `@ManyToOne(fetch = LAZY)` para `Usuario`
- `nome` String NOT NULL
- `marca` String nullable
- `unidadeMedida` String NOT NULL
- `custoUnitario` BigDecimal default 0 (atualizado a cada compra)
- `estoqueAtual` BigDecimal default 0
- `estoqueMinimo` BigDecimal nullable
- `ativo` boolean default true
- `deletedAt` LocalDateTime nullable
- `createdAt` LocalDateTime → `@CreationTimestamp`
- `updatedAt` LocalDateTime → `@UpdateTimestamp`

Constraint de unicidade: `@Table(uniqueConstraints = @UniqueConstraint(columnNames = {"nome", "marca", "usuario_id"}))`

### 3. Entity: `MovimentacaoInsumo` (em `domain/entity/`)

Campos:
- `id` UUID PK
- `insumo` → `@ManyToOne(fetch = LAZY)` para `Insumo`
- `tipo` → `TipoMovimentacaoInsumo` (`@Enumerated(EnumType.STRING)`)
- `motivo` → `MotivoMovimentacaoInsumo` (`@Enumerated(EnumType.STRING)`)
- `quantidade` BigDecimal NOT NULL
- `observacao` String nullable (validação de mín. 50 chars será feita no Service)
- `referenciaId` UUID nullable
- `referenciaTipo` → `ReferenciaMovimentacaoTipo` nullable (`@Enumerated(EnumType.STRING)`)
- `estornada` boolean default false
- `createdAt` LocalDateTime → `@CreationTimestamp`

**Sem `updatedAt` em MovimentacaoInsumo** — movimentações são imutáveis (nunca editadas, apenas estornadas via nova linha).

### 4. Repository: `InsumoRepository` (em `domain/repository/`)

```java
public interface InsumoRepository extends JpaRepository<Insumo, UUID> {

    // Listar ativos do usuário (paginado)
    Page<Insumo> findByUsuarioIdAndDeletedAtIsNull(UUID usuarioId, Pageable pageable);

    // Buscar por id garantindo que pertence ao usuário
    Optional<Insumo> findByIdAndUsuarioIdAndDeletedAtIsNull(UUID id, UUID usuarioId);

    // Verificar unicidade nome+marca para o usuário (excluindo o próprio registro no update)
    boolean existsByNomeAndMarcaAndUsuarioIdAndDeletedAtIsNull(
        String nome, String marca, UUID usuarioId);

    boolean existsByNomeAndMarcaAndUsuarioIdAndIdNotAndDeletedAtIsNull(
        String nome, String marca, UUID usuarioId, UUID id);
}
```

### 5. Repository: `MovimentacaoInsumoRepository` (em `domain/repository/`)

```java
public interface MovimentacaoInsumoRepository extends JpaRepository<MovimentacaoInsumo, UUID> {

    // Histórico paginado de um insumo (mais recente primeiro)
    Page<MovimentacaoInsumo> findByInsumoIdOrderByCreatedAtDesc(UUID insumoId, Pageable pageable);

    // Buscar movimentações por referência (ex: todas do mesmo lote de compra)
    List<MovimentacaoInsumo> findByReferenciaIdAndReferenciaTipo(
        UUID referenciaId, ReferenciaMovimentacaoTipo referenciaTipo);
}
```
