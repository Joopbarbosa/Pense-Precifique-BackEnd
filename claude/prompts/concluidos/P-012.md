**Camada:** back
**Depende de:** P-010 (Empresa entity/repository), P-011 (DTOs), P-005 (Security — usuário autenticado), P-007 (GlobalExceptionHandler)

## Contexto para o Claude Code

Esta tarefa implementa o CRUD do perfil da empresa (aba "Perfil da empresa" na tela de
Configurações, e também usado no Onboarding — Tela 3 — após o cadastro).

**Endpoint (CLAUDE.md):**
| Método | Endpoint | Descrição |
|--------|----------|-----------|
| GET/PUT | /empresa | Perfil da empresa |

**Comportamento especial — "criar ou atualizar" (upsert):**
Diferente de outros recursos (Clientes, Insumos, etc.), `Empresa` tem uma relação 1:1
com `Usuario`, e é criada **no primeiro acesso** (onboarding), não via um endpoint
`POST /empresa` separado. Portanto:

- `GET /empresa`:
  - Se já existe uma `Empresa` para o usuário autenticado → retorna `200` com
    `EmpresaResponseDTO`
  - Se **não existe ainda** (usuário acabou de se cadastrar, ainda não passou pelo
    onboarding) → retorna `404 Not Found` (use `ResourceNotFoundException`, já criada
    em P-007) com mensagem "Perfil da empresa não configurado"

- `PUT /empresa`:
  - Se já existe uma `Empresa` para o usuário → atualiza os campos
  - Se **não existe ainda** → cria uma nova `Empresa` vinculada ao `usuarioId` do
    usuário autenticado (comportamento de upsert — isso é o que o Onboarding vai usar
    para criar o perfil pela primeira vez)

**Como obter o usuário autenticado:** mesmo padrão do P-008 — extrair o email do
`SecurityContextHolder`, buscar o `Usuario` via `UsuarioRepository`, usar
`usuario.getId()` como `usuarioId`.

**Cenário de aceite:** sem cenário BDD numerado específico (Épico 2 "sem alterações").
Critério funcional:
- `GET /empresa` sem perfil configurado → `404`
- `PUT /empresa` com dados válidos (primeira vez) → `200`, cria o registro
- `GET /empresa` após o PUT → `200` com os dados salvos
- `PUT /empresa` novamente (atualização) → `200`, atualiza os campos existentes (não
  cria um segundo registro)
- `PUT /empresa` sem `nome` → `400` (validação)

### 1. `service/EmpresaService.java` (interface)

```java
public interface EmpresaService {

}
```

### 2. `service/impl/EmpresaServiceImpl.java`

Anotações: `@Service`, `@RequiredArgsConstructor` injetando `EmpresaRepository`,
`UsuarioRepository`.

Crie (ou reutilize, se já existir um utilitário comum) um método para obter o
`usuarioId` autenticado:
```java
private UUID getUsuarioIdAutenticado() {
    String email = SecurityContextHolder.getContext().getAuthentication().getName();
    return usuarioRepository.findByEmailAndDeletedAtIsNull(email)
        .orElseThrow(() -> new BusinessException("Usuário autenticado não encontrado"))
        .getId();
}
```

**`getEmpresa()`:**
1. `usuarioId = getUsuarioIdAutenticado()`
2. Busque via `empresaRepository.findByUsuarioIdAndDeletedAtIsNull(usuarioId)`
3. Se não encontrado → `throw new ResourceNotFoundException("Perfil da empresa não configurado")`
4. Se encontrado → mapeie para `EmpresaResponseDTO` e retorne

**`upsertEmpresa(EmpresaRequestDTO request)`:**
1. `usuarioId = getUsuarioIdAutenticado()`
2. Busque a `Empresa` existente via `findByUsuarioIdAndDeletedAtIsNull(usuarioId)`
3. Se existir → atualize os campos (`nome`, `email`, `whatsapp`, `endereco`, `logoUrl`)
   com os valores do `request` (apenas sobrescreva campos presentes — mas como o DTO
   não distingue "campo não enviado" de "campo vazio" neste design simples, sobrescreva
   todos os campos do request diretamente)
4. Se não existir → crie uma nova `Empresa` com `usuarioId` e os campos do `request`
5. Salve via `empresaRepository.save(...)`
6. Mapeie para `EmpresaResponseDTO` e retorne

Mapeamento DTO ↔ Entity pode ser manual (métodos privados) ou via MapStruct — se o
projeto já tiver outros Mappers MapStruct, siga o padrão; caso contrário, mapeamento
manual é aceitável para este DTO simples.

### 3. `controller/EmpresaController.java`

```java
@RestController
@RequestMapping("/empresa")
@RequiredArgsConstructor
public class EmpresaController {

    private final EmpresaService empresaService;

    @GetMapping
    public ResponseEntity<EmpresaResponseDTO> getEmpresa() {
        return ResponseEntity.ok(empresaService.getEmpresa());
    }

    @PutMapping
    public ResponseEntity<EmpresaResponseDTO> upsertEmpresa(@Valid @RequestBody EmpresaRequestDTO request) {
        return ResponseEntity.ok(empresaService.upsertEmpresa(request));
    }
}
```

### 4. Adicione o handler de `ResourceNotFoundException` no `GlobalExceptionHandler`

Se ainda não existir (verifique o arquivo criado em P-007 — a classe
`ResourceNotFoundException` já existe vazia, mas pode não ter handler ainda):

```java
@ExceptionHandler(ResourceNotFoundException.class)
public ResponseEntity<ErrorResponseDTO> handleResourceNotFound(ResourceNotFoundException ex) {
    ErrorResponseDTO error = new ErrorResponseDTO(ex.getMessage(), HttpStatus.NOT_FOUND.value(), LocalDateTime.now(), null);
    return ResponseEntity.status(HttpStatus.NOT_FOUND).body(error);
}
```
