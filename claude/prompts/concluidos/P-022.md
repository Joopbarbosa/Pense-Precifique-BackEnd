### 1. `src/services/insumoService.ts` (novo arquivo)

```ts
import api from './api';
import type { InsumoResponse, PageResponse } from '../types/insumo';

export const insumoService = {
  listar: async (page: number, size = 20, busca?: string): Promise<PageResponse<InsumoResponse>> => {
    const params: Record<string, any> = { page, size, sort: 'nome' };
    if (busca) params.busca = busca;
    const response = await api.get('/insumos', { params });
    return response.data;
  },

  buscarPorId: async (id: string): Promise<InsumoResponse> => {
    const response = await api.get(`/insumos/${id}`);
    return response.data;
  },

  cadastrar: async (data: InsumoRequest): Promise<InsumoResponse> => {
    const response = await api.post('/insumos', data);
    return response.data;
  },

  editar: async (id: string, data: InsumoRequest): Promise<InsumoResponse> => {
    const response = await api.put(`/insumos/${id}`, data);
    return response.data;
  },

  inativar: async (id: string): Promise<void> => {
    await api.delete(`/insumos/${id}`);
  },
};
```

### 2. `src/types/insumo.ts` (novo arquivo)

```ts
export interface InsumoRequest {
  nome: string;
  marca?: string;
  unidadeMedida: string;
  estoqueAtual?: number;
  estoqueMinimo?: number;
}

export interface InsumoResponse {
  id: string;
  nome: string;
  marca?: string;
  unidadeMedida: string;
  custoUnitario: number;
  estoqueAtual: number;
  estoqueMinimo?: number;
  ativo: boolean;
  createdAt: string;
  updatedAt: string;
}

export interface PageResponse<T> {
  content: T[];
  page: number;
  size: number;
  totalElements: number;
  hasNext: boolean;
}
```

### 3. Conectar `ListaInsumosPage`:

- Ao montar: chama `insumoService.listar(0)` → popula lista com os primeiros 20 itens
- Estado local: `insumos: InsumoResponse[]`, `page: number`, `hasNext: boolean`, `loading: boolean`, `busca: string`
- Botão "Carregar mais": chama `listar(page + 1)` e **acumula** os resultados (não substitui)
- Campo de busca: ao alterar, **reseta** `page = 0` e `insumos = []` antes de buscar (RN-034)
- Botão "Registrar compra": mantém o comportamento visual atual (o modal de lote será conectado no P-029 — por ora, pode deixar o handler vazio ou com `// TODO P-029`)
- Ação de inativar insumo (menu ⋮ ou botão existente na tela): chama `insumoService.inativar(id)` e remove da lista local
- Estado de loading durante carregamento

### Convenções:
- Não altere layout/estilos
- Reutilize hooks/componentes de UI já existentes (toasts, loading states)
- Nenhum container ancestral da lista pode ter `overflow: hidden` (pode causar corte de dropdowns)
