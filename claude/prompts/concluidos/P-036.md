Adicione o fluxo de baixa manual ao `ProdutoService` e exponha o endpoint no `ProdutoController`.

**Leia o CLAUDE.md antes de começar.**

### 1. Adicionar ao `ProdutoService`:

```java
public MovimentacaoProdutoResponse baixaManual(UUID produtoId, BaixaManualProdutoRequest request, UUID usuarioId);
```

**Lógica:**
1. Buscar produto por `produtoId` e `usuarioId` (`ResourceNotFoundException` se não encontrado)
2. Verificar `estoqueAtual >= request.getQuantidade()` → `BusinessException("Estoque insuficiente para realizar a baixa.")` se não
3. Subtrair `request.getQuantidade()` do `estoqueAtual`
4. Criar `MovimentacaoProduto`:
   - `tipo = SAIDA`
   - `motivo = request.getMotivo()`
   - `quantidade = request.getQuantidade()`
   - `observacao = request.getObservacao()`
   - `estornada = false`
   - `referenciaId = null`
5. Salvar produto e movimentação
6. Retornar `MovimentacaoProdutoResponse`

### 2. Adicionar ao `ProdutoController`:

```java
@PostMapping("/{id}/baixa-manual")
public ResponseEntity<MovimentacaoProdutoResponse> baixaManual(
        @PathVariable UUID id,
        @Valid @RequestBody BaixaManualProdutoRequest request,
        @AuthenticationPrincipal UserDetails userDetails) {
    UUID usuarioId = extrairUsuarioId(userDetails);
    return ResponseEntity.status(201).body(produtoService.baixaManual(id, request, usuarioId));
}
```

Compile ao final:
```bash
./mvnw compile -q
```
