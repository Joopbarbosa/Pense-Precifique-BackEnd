Adicione o endpoint de cancelamento ao `ProducaoController`.

**Leia o CLAUDE.md antes de começar.**

```java
@PostMapping("/{id}/cancelar")
public ResponseEntity<ProducaoDetalheResponse> cancelar(
        @PathVariable UUID id,
        @Valid @RequestBody CancelarProducaoRequest request,
        @AuthenticationPrincipal UserDetails userDetails) {
    UUID usuarioId = extrairUsuarioId(userDetails);
    return ResponseEntity.ok(producaoService.cancelar(id, request, usuarioId));
}
```

Compile ao final:
```bash
./mvnw compile -q
```
