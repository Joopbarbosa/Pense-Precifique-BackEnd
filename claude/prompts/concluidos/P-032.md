### Métodos obrigatórios:

```java
@Component
public class ProdutoMapper {

    // Produto → ProdutoResponse (listagem, sem ficha técnica)
    public ProdutoResponse toResponse(Produto produto);

    // Produto + itens ficha → ProdutoDetalheResponse
    public ProdutoDetalheResponse toDetalheResponse(Produto produto, List<FichaTecnicaItem> itens);

    // ProdutoRequest → Produto (novo cadastro)
    public Produto toEntity(ProdutoRequest request, Usuario usuario);

    // Atualiza campos de um Produto existente (não toca em precoCusto nem estoqueAtual)
    public void updateEntity(ProdutoRequest request, Produto produto);

    // FichaTecnicaItem → FichaTecnicaItemResponse
    public FichaTecnicaItemResponse toFichaTecnicaItemResponse(FichaTecnicaItem item);

    // MovimentacaoProduto → MovimentacaoProdutoResponse
    public MovimentacaoProdutoResponse toMovimentacaoResponse(MovimentacaoProduto mov);
}
```

### Regras de mapeamento:

- `toFichaTecnicaItemResponse`:
  - Se `item.getInsumo() != null`: preenche `insumoId`, `nomeInsumo`, `marcaInsumo`, `unidadeMedida`, `custoUnitario = insumo.getCustoUnitario()`
  - Se `item.getProdutoBase() != null`: preenche `produtoBaseId`, `nomeProdutoBase`, `custoUnitario = produtoBase.getPrecoCusto()`
  - `custoTotal = quantidade.multiply(custoUnitario)`

- `toEntity`: `precoCusto = BigDecimal.ZERO`, `estoqueAtual = BigDecimal.ZERO`, `ativo = true`

- `updateEntity`: atualiza `nome`, `tipo`, `descricao`, `tempoProducao`, `foto`, `precoVenda`, `estoqueMinimo` — **não** toca em `precoCusto` nem `estoqueAtual`

Compile ao final:
```bash
./mvnw compile -q
```
