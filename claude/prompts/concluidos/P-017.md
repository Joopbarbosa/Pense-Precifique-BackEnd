### Métodos obrigatórios:

```java
@Component
public class InsumoMapper {

    // Insumo → InsumoResponse
    public InsumoResponse toResponse(Insumo insumo);

    // InsumoRequest → Insumo (novo cadastro)
    public Insumo toEntity(InsumoRequest request, Usuario usuario);

    // Atualiza campos de um Insumo existente a partir de InsumoRequest
    public void updateEntity(InsumoRequest request, Insumo insumo);

    // MovimentacaoInsumo → MovimentacaoInsumoResponse
    public MovimentacaoInsumoResponse toMovimentacaoResponse(MovimentacaoInsumo mov);

    // List<Insumo> → List<InsumoResponse>
    public List<InsumoResponse> toResponseList(List<Insumo> insumos);
}
```

### Regras de mapeamento:
- `toEntity`: `estoqueAtual` default `BigDecimal.ZERO` se nulo no request; `custoUnitario` default `BigDecimal.ZERO`; `ativo = true`
- `updateEntity`: atualiza apenas `nome`, `marca`, `unidadeMedida`, `estoqueMinimo` — **não** atualiza `custoUnitario` nem `estoqueAtual` (esses só mudam via movimentação)
- `toMovimentacaoResponse`: mapeia todos os campos incluindo `estornada`

Compile ao final:
```bash
./mvnw compile -q
```
