## Contexto para o Claude Code

**Soft delete de clientes:** inativar um cliente seta `ativa = false` e `deletedAt = LocalDateTime.now()`. Clientes inativos não aparecem na listagem, mas seus orçamentos continuam existindo.

**RN-034:** listagem paginada, 20 itens por página, com filtro opcional por nome.

### Métodos obrigatórios:

```java
@Service
@Transactional
public class ClienteService {

    // Listar clientes ativos do usuário (paginado, filtro opcional por nome)
    public Page<ClienteResponse> listar(UUID usuarioId, String nome, Pageable pageable);

    // Buscar por id
    public ClienteResponse buscarPorId(UUID id, UUID usuarioId);

    // Cadastrar novo cliente
    public ClienteResponse cadastrar(ClienteRequest request, UUID usuarioId);

    // Editar cliente existente
    public ClienteResponse editar(UUID id, ClienteRequest request, UUID usuarioId);

    // Inativar (soft delete: ativa=false + deletedAt=now)
    public void inativar(UUID id, UUID usuarioId);
}
```

### Lógica de `listar`:

```java
if (nome != null && !nome.isBlank()) {
    return clienteRepository
        .findByUsuarioIdAndNomeContainingIgnoreCaseAndDeletedAtIsNull(usuarioId, nome, pageable)
        .map(clienteMapper::toResponse);
} else {
    return clienteRepository
        .findByUsuarioIdAndDeletedAtIsNull(usuarioId, pageable)
        .map(clienteMapper::toResponse);
}
```

### Lógica de `inativar`:

```java
Cliente cliente = clienteRepository
    .findByIdAndUsuarioIdAndDeletedAtIsNull(id, usuarioId)
    .orElseThrow(() -> new ResourceNotFoundException("Cliente não encontrado: " + id));
cliente.setAtiva(false);
cliente.setDeletedAt(LocalDateTime.now());
clienteRepository.save(cliente);
```

Compile ao final:
```bash
./mvnw compile -q
```
