### Métodos obrigatórios:

```java
@Service
@Transactional
public class ProdutoService {

    // Listar produtos ativos do usuário (paginado, filtro opcional por tipo)
    public Page<ProdutoResponse> listar(UUID usuarioId, TipoProduto tipo, Pageable pageable);

    // Buscar por id com ficha técnica completa
    public ProdutoDetalheResponse buscarPorId(UUID id, UUID usuarioId);

    // Cadastrar produto com ficha técnica
    public ProdutoDetalheResponse cadastrar(ProdutoRequest request, UUID usuarioId);

    // Editar produto e substituir ficha técnica
    public ProdutoDetalheResponse editar(UUID id, ProdutoRequest request, UUID usuarioId);

    // Inativar (soft delete)
    public void inativar(UUID id, UUID usuarioId);
}
```

### Validação de precoVenda (aplicar em `cadastrar` e `editar`):

```java
private void validarPrecoVenda(ProdutoRequest request) {
    if (request.getTipo() == TipoProduto.PRODUTO_BASE) {
        if (request.getPrecoVenda() != null) {
            throw new BusinessException("Produto Base não pode ter preço de venda.");
        }
    } else {
        if (request.getPrecoVenda() == null || request.getPrecoVenda().compareTo(BigDecimal.ZERO) <= 0) {
            throw new BusinessException("Preço de venda é obrigatório para Produto e Customização.");
        }
    }
}
```

### Fluxo de `cadastrar`:

```
1. validarPrecoVenda(request)
2. produto = produtoMapper.toEntity(request, usuario)
3. produto = produtoRepository.save(produto)
4. precoCusto = fichaTecnicaService.salvarFichaTecnica(produto, request.getFichaTecnica(), usuarioId)
5. produto.setPrecoCusto(precoCusto)
6. produtoRepository.save(produto)
7. itens = fichaTecnicaItemRepository.findByProdutoId(produto.getId())
8. return produtoMapper.toDetalheResponse(produto, itens)
```

### Fluxo de `editar`:

```
1. buscar produto por id e usuarioId (ResourceNotFoundException se não encontrado)
2. validarPrecoVenda(request)
3. produtoMapper.updateEntity(request, produto)
4. precoCusto = fichaTecnicaService.salvarFichaTecnica(produto, request.getFichaTecnica(), usuarioId)
5. produto.setPrecoCusto(precoCusto)
6. produtoRepository.save(produto)
7. itens = fichaTecnicaItemRepository.findByProdutoId(produto.getId())
8. return produtoMapper.toDetalheResponse(produto, itens)
```

### Fluxo de `listar`:

- Se `tipo != null`: usar `findByUsuarioIdAndTipoAndDeletedAtIsNull`
- Se `tipo == null`: usar `findByUsuarioIdAndDeletedAtIsNull`
