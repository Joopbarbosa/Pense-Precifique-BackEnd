### 1. `src/services/api.ts`
Crie (se não existir) uma instância do axios:
```ts
import axios from 'axios';

const api = axios.create({
  baseURL: import.meta.env.VITE_API_URL || 'http://localhost:8080',
});

api.interceptors.request.use((config) => {
  const token = useAuthStore.getState().token; // ajuste conforme o store real
  if (token) {
    config.headers.Authorization = `Bearer ${token}`;
  }
  return config;
});

api.interceptors.response.use(
  (response) => response,
  (error) => {
    if (error.response?.status === 401) {
      // token inválido/expirado → limpar auth e redirecionar para login
      useAuthStore.getState().logout();
      window.location.href = '/login';
    }
    return Promise.reject(error);
  }
);

export default api;
```
Ajuste o import circular entre `api.ts` e `authStore.ts` se necessário (ex: usando
`getState()` do Zustand evita import circular, mas verifique).

### 3. `src/services/authService.ts`
```ts
import api from './api';
import type { LoginRequest, CadastroRequest, AuthResponse, UsuarioResponse } from '../types/auth';

export const authService = {
  login: async (data: LoginRequest): Promise<AuthResponse> => {
    const response = await api.post<AuthResponse>('/auth/login', data);
    return response.data;
  },
  register: async (data: CadastroRequest): Promise<AuthResponse> => {
    const response = await api.post<AuthResponse>('/auth/register', data);
    return response.data;
  },
  getMe: async (): Promise<UsuarioResponse> => {
    const response = await api.get<UsuarioResponse>('/usuarios/me');
    return response.data;
  },
};
```

### 4. `src/store/authStore.ts`
Crie (ou ajuste se já existir) uma store Zustand:
```ts
import { create } from 'zustand';
import { persist } from 'zustand/middleware';

interface AuthState {
  token: string | null;
  usuarioId: string | null;
  email: string | null;
  setAuth: (data: { token: string; usuarioId: string; email: string }) => void;
  logout: () => void;
  isAuthenticated: () => boolean;
}

export const useAuthStore = create<AuthState>()(
  persist(
    (set, get) => ({
      token: null,
      usuarioId: null,
      email: null,
      setAuth: ({ token, usuarioId, email }) => set({ token, usuarioId, email }),
      logout: () => set({ token: null, usuarioId: null, email: null }),
      isAuthenticated: () => !!get().token,
    }),
    { name: 'auth-storage' }
  )
);
```
Se o projeto já tiver uma `authStore.ts` com estrutura diferente, **adapte mantendo a
estrutura existente** em vez de substituir — apenas garanta que exista `token` e os
métodos `setAuth`/`logout`.

### 5. Conectar `LoginPage.tsx`
- No submit do formulário de login:
  - Chame `authService.login({ email, senha })`
  - Em caso de sucesso: `useAuthStore.getState().setAuth({ token: response.token,
    usuarioId: response.usuarioId, email: response.email })` e redirecione para
    `/dashboard` (ou a rota inicial pós-login definida nas rotas existentes — verifique
    `src/routes/index.tsx`)
  - Em caso de erro (`AxiosError` com `response.data` no formato `ApiErrorResponse`):
    exiba `error.response.data.message` no formulário (use o mecanismo de exibição de
    erro já existente na tela — toast, mensagem inline, etc. — conforme padrão do
    projeto; se houver `useToast` hook em `src/hooks/useToast.ts`, use-o)
  - Estado de loading durante a chamada (desabilitar botão de submit)

### 6. Conectar `CadastroPage.tsx`
- No submit do formulário de cadastro:
  - Chame `authService.register({ email, senha, confirmarSenha })`
  - Em caso de sucesso: mesma lógica de `setAuth` + redirecionamento (para
    `/onboarding`, Tela 3, já que é o primeiro acesso — verifique se essa rota já
    existe em `src/routes/index.tsx`; se a rota de onboarding ainda não existir,
    redirecione para `/dashboard` por enquanto e deixe um comentário `// TODO: Épico 2
    — redirecionar para /onboarding quando implementado`)
  - Em caso de erro: exiba `error.response.data.message` (ex: "E-mail já cadastrado",
    "As senhas não coincidem") no formulário
  - Se `error.response.data.fieldErrors` existir, exiba os erros por campo (ex: campo
    `senha` com mensagem de tamanho mínimo)
  - Estado de loading durante a chamada
