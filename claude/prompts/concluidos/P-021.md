## Prompt

Cole este prompt no Claude Code:

---

Adicione o endpoint de histórico de movimentações de insumo ao `InsumoService` e `InsumoController`.

**Leia o CLAUDE.md antes de começar.**

### 1. Adicionar ao `InsumoService`:

```java
// Histórico paginado de movimentações de um insumo
public Page<MovimentacaoInsumoResponse> listarMovimentacoes(UUID insumoId, UUID usuarioId, Pageable pageable);
```

**Lógica:**
1. Verificar que o insumo existe e pertence ao usuário (`buscarPorId` interno ou `findByIdAndUsuarioIdAndDeletedAtIsNull`)
2. Buscar movimentações via `movimentacaoInsumoRepository.findByInsumoIdOrderByCreatedAtDesc(insumoId, pageable)`
3. Mapear para `Page<MovimentacaoInsumoResponse>` usando o mapper

### 2. Adicionar ao `InsumoController`:

```
GET /insumos/{id}/movimentacoes
```

```java
@GetMapping("/{id}/movimentacoes")
public ResponseEntity<Page<MovimentacaoInsumoResponse>> listarMovimentacoes(
        @PathVariable UUID id,
        @AuthenticationPrincipal UserDetails userDetails,
        @PageableDefault(size = 20) Pageable pageable) {
    UUID usuarioId = extrairUsuarioId(userDetails);
    return ResponseEntity.ok(insumoService.listarMovimentacoes(id, usuarioId, pageable));
}
```

Compile ao final:
```bash
./mvnw compile -q
```
