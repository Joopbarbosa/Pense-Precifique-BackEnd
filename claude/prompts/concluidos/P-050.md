# P-050 — Service: ProducaoService — lançar produção

**Épico:** Épico 6 — Registro de Produção
**Camada:** back
**Depende de:** P-047, P-048, P-049
**Modelo recomendado:** Opus

---

## Contexto para o Claude Code

Este é o service mais crítico do Épico 6. Implementa o lançamento de produção:
- Baixa os insumos da ficha técnica do produto proporcional à quantidade produzida
- Adiciona ao estoque do produto produzido
- Registra movimentações de insumo (SAIDA/PRODUCAO) e de produto (ENTRADA/PRODUCAO)
- Registra os insumos consumidos em `ProducaoInsumoConsumido`

**Regra de negócio:** o sistema deve verificar se há estoque suficiente de cada insumo antes de lançar. Se qualquer insumo estiver insuficiente, lança `BusinessException` com a lista de insumos problemáticos.

### Métodos obrigatórios:

```java
@Service
@Transactional
public class ProducaoService {

    // Listar produções do usuário (paginado, mais recente primeiro)
    public Page<ProducaoResponse> listar(UUID usuarioId, Pageable pageable);

    // Buscar detalhe de uma produção
    public ProducaoDetalheResponse buscarPorId(UUID id, UUID usuarioId);

    // Lançar produção
    public ProducaoDetalheResponse lancar(LancarProducaoRequest request, UUID usuarioId);

    // Buscar insumos que seriam consumidos (para preview na UI antes de confirmar)
    public List<InsumoConsumidoResponse> previewInsumosConsumidos(UUID produtoId, BigDecimal quantidade, UUID usuarioId);
}
```

### Lógica de `previewInsumosConsumidos`:

```
1. Buscar produto por produtoId e usuarioId
2. Buscar ficha técnica do produto (FichaTecnicaItemRepository.findByProdutoId)
3. Para cada item da ficha técnica:
   a. Calcular quantidadeNecessaria = item.getQuantidade() × quantidade
   b. Buscar estoqueAtual do insumo (ou precoCusto do produto base)
   c. Montar InsumoConsumidoResponse com estoqueInsuficiente = estoqueAtual < quantidadeNecessaria
4. Retornar lista
```

### Lógica de `lancar`:

```
1. Buscar produto por produtoId e usuarioId (ResourceNotFoundException se não encontrado)
2. Chamar previewInsumosConsumidos para verificar suficiência
3. Se algum insumo tiver estoqueInsuficiente = true:
   → lançar BusinessException("Estoque insuficiente para os insumos: [lista de nomes]")
4. Criar Producao:
   - usuario, produto, quantidade
   - dataProducao = request.getDataProducao() != null ? request.getDataProducao() : LocalDateTime.now()
   - status = ATIVA
   - numero: buscar MAX(numero) do usuário e incrementar (ou 1 se não houver)
5. Salvar Producao
6. Para cada item da ficha técnica:
   a. Calcular quantidadeConsumida = item.getQuantidade() × request.getQuantidade()
   b. Se componente for Insumo:
      - Subtrair quantidadeConsumida do insumo.estoqueAtual
      - Salvar insumo
      - Criar MovimentacaoInsumo (tipo=SAIDA, motivo=PRODUCAO, referenciaId=producao.id, referenciaTipo=PRODUCAO)
      - Criar ProducaoInsumoConsumido (producao, insumo, quantidadeConsumida)
   c. Se componente for ProdutoBase:
      - Subtrair quantidadeConsumida do produtoBase.estoqueAtual
      - Salvar produtoBase
      - Criar MovimentacaoProduto (tipo=SAIDA, motivo=PRODUCAO, referenciaId=producao.id)
      - Criar ProducaoInsumoConsumido (producao, insumo=null — registrar apenas quantidade)
7. Adicionar request.getQuantidade() ao produto.estoqueAtual
8. Salvar produto
9. Criar MovimentacaoProduto (tipo=ENTRADA, motivo=PRODUCAO, referenciaId=producao.id)
10. Retornar ProducaoDetalheResponse
```

### Geração do número sequencial:

```java
// Buscar o maior número já usado pelo usuário e incrementar
Integer maxNumero = producaoRepository.findByUsuarioIdOrderByDataProducaoDesc(usuarioId, PageRequest.of(0, 1))
    .stream()
    .mapToInt(p -> p.getNumero() != null ? p.getNumero() : 0)
    .max()
    .orElse(0);
producao.setNumero(maxNumero + 1);
```
