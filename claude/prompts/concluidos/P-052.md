## Contexto para o Claude Code

**RN-037 — Cancelamento de produção** com suporte a componentes do tipo `produto-base`.

Após o fix aplicado antes do P-051, `ProducaoInsumoConsumido` pode ter:
- `insumo != null` e `produtoBase == null` → componente é um insumo
- `insumo == null` e `produtoBase != null` → componente é um produto-base

O cancelamento deve tratar os dois casos ao reverter estoque e criar movimentações de estorno.

Adicione o método `cancelar` ao `ProducaoService`.

**Leia o CLAUDE.md e o `ProducaoService.java` existente antes de começar. O service resolve usuário via SecurityContext — não adicione parâmetro usuarioId.**

### Assinatura:

```java
public ProducaoDetalheResponse cancelar(UUID id, CancelarProducaoRequest request);
```

### Lógica de `cancelar`:

```
1. Resolver usuarioId via SecurityContext (mesmo padrão do service)
2. Buscar produção por id e usuarioId (ResourceNotFoundException se não encontrada)
3. Validar que status == ATIVA
   → se CANCELADA: lançar BusinessException("Esta produção já foi cancelada.")

4. Buscar todos os ProducaoInsumoConsumido da produção

5. Reverter estoque do produto produzido:
   - produto.estoqueAtual -= producao.quantidade
   - salvar produto
   - Buscar MovimentacaoProduto original (motivo=PRODUCAO, tipo=ENTRADA, referenciaId=producao.id)
   - setar original.estornada = true, salvar
   - Criar nova MovimentacaoProduto (tipo=SAIDA, motivo=ESTORNO_PRODUCAO,
     quantidade=producao.quantidade, observacao=request.getObservacao(),
     referenciaId=producao.id, estornada=false)

6. Para cada ProducaoInsumoConsumido:

   BRANCH A — consumido.getInsumo() != null (componente é insumo):
   - insumo.estoqueAtual += consumido.getQuantidade()
   - salvar insumo
   - Buscar MovimentacaoInsumo original (motivo=PRODUCAO, referenciaId=producao.id, insumoId=insumo.id)
   - setar original.estornada = true, salvar
   - Criar nova MovimentacaoInsumo (tipo=ENTRADA, motivo=ESTORNO_PRODUCAO,
     quantidade=consumido.getQuantidade(), observacao=request.getObservacao(),
     referenciaId=producao.id, referenciaTipo=PRODUCAO, estornada=false)

   BRANCH B — consumido.getProdutoBase() != null (componente é produto-base):
   - produtoBase.estoqueAtual += consumido.getQuantidade()
   - salvar produtoBase
   - Buscar MovimentacaoProduto original (motivo=PRODUCAO, tipo=SAIDA,
     referenciaId=producao.id, produtoId=produtoBase.id)
   - setar original.estornada = true, salvar
   - Criar nova MovimentacaoProduto (tipo=ENTRADA, motivo=ESTORNO_PRODUCAO,
     quantidade=consumido.getQuantidade(), observacao=request.getObservacao(),
     referenciaId=producao.id, estornada=false)

7. Atualizar producao:
   - status = CANCELADA
   - observacaoCancelamento = request.getObservacao()
   - dataCancelamento = LocalDateTime.now()
   - salvar producao

8. Retornar ProducaoDetalheResponse atualizado
```
