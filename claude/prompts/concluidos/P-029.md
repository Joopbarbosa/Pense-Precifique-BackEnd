## Contexto para o Claude Code

**RN-036:** compras de insumos são feitas exclusivamente via modal de "carrinho de compras" na ListaInsumosPage. A artesã adiciona múltiplos insumos, informa quantidade e preço total de cada um, confirma o lote e vê o modal de impacto agregado.

**Errata v6:**
- Sem opção "Cadastrar novo insumo" dentro do modal
- Sem botão de compra individual no Detalhe do Insumo

**Cenário BDD (Cenário 79):**
```gherkin
Dado que a artesã está na Lista de Insumos
Quando clica em "Registrar compra"
Então sistema abre modal "Carrinho de compras"
Quando adiciona "Papel Couché 250g" (500 unidades, R$ 250,00)
E adiciona "Cola Branca 1L" (3 unidades, R$ 45,00)
E confirma o lote
Então sistema recalcula custos, atualiza estoques
E exibe modal de impacto agregado com custos anteriores e novos
```

**Cenário 80:**
```gherkin
Dado que a artesã está no modal "Carrinho de compras"
Então não há opção "Cadastrar novo insumo" disponível
```

**Endpoint:** `POST /lotes-compra`

## Prompt

Cole este prompt no Claude Code:

---

Implemente o modal de "Carrinho de compras" na `ListaInsumosPage` e o modal de impacto agregado.

**Leia o CLAUDE.md antes de começar. Leia o conteúdo atual da tela antes de editar.**

### 1. Adicionar ao `insumoService.ts`:

```ts
// Busca insumos para o buscador do modal (reutiliza listar com busca)
buscarParaCarrinho: async (busca: string): Promise<InsumoResponse[]> => {
  const response = await api.get('/insumos', { params: { page: 0, size: 20, busca, sort: 'nome' } });
  return response.data.content;
},
```

### 2. Adicionar ao `src/services/loteCompraService.ts` (novo arquivo):

```ts
import api from './api';
import type { ImpactoAgregadoResponse, RegistrarLoteCompraRequest } from '../types/loteCompra';

export const loteCompraService = {
  registrar: async (data: RegistrarLoteCompraRequest): Promise<ImpactoAgregadoResponse> => {
    const response = await api.post('/lotes-compra', data);
    return response.data;
  },
};
```

### 3. Adicionar ao `src/types/loteCompra.ts` (novo arquivo):

```ts
export interface ItemLoteCompraRequest {
  insumoId: string;
  quantidadeComprada: number;
  precoTotalPago: number;
}

export interface RegistrarLoteCompraRequest {
  dataCompra?: string; // ISO datetime, opcional
  itens: ItemLoteCompraRequest[];
}

export interface InsumoImpactoResponse {
  insumoId: string;
  nomeInsumo: string;
  marca?: string;
  unidadeMedida: string;
  custoUnitarioAnterior: number;
  custoUnitarioNovo: number;
  quantidadeAdicionada: number;
}

export interface ImpactoAgregadoResponse {
  loteId: string;
  dataCompra: string;
  insumosAtualizados: InsumoImpactoResponse[];
  produtosAfetados: any[];
}
```

### 4. Modal "Carrinho de compras":

**Estado local do modal:**
- `itens: Array<{ insumo: InsumoResponse, quantidade: number, precoTotal: number }>`
- `busca: string` para o campo de busca de insumos
- `resultadosBusca: InsumoResponse[]`
- `loading: boolean`

**Comportamento:**
- Campo de busca: ao digitar (debounce 300ms), chama `insumoService.buscarParaCarrinho(busca)`
- Ao selecionar insumo nos resultados: adiciona ao carrinho com quantidade=1 e precoTotal=0
- Cada item do carrinho tem campos editáveis: quantidade (numérico) e preço total pago (monetário)
- Botão de remover item do carrinho
- **Sem** opção "Cadastrar novo insumo" (Cenário 80)
- Botão "Confirmar compra": desabilitado se carrinho vazio ou algum item com quantidade/preço zerado
- Ao confirmar: chama `loteCompraService.registrar({ itens: [...] })`
- Sucesso: fecha modal do carrinho → abre modal de impacto agregado → recarrega lista de insumos

### 5. Modal de impacto agregado:

Exibe `ImpactoAgregadoResponse.insumosAtualizados` em formato de tabela ou lista:
- Nome do insumo
- Custo anterior → Custo novo (com indicação visual de aumento/redução)
- Quantidade adicionada
- Botão "Fechar" → retorna para a lista de insumos atualizada

Se `produtosAfetados` não for vazio no futuro, a estrutura já deve suportar exibição (por ora lista vazia, não precisa tratar).

### Convenções:
- Nenhum container ancestral dos modais pode ter `overflow: hidden`
- Não altere layout/estilos existentes
- Reutilize componentes de modal já existentes no projeto
