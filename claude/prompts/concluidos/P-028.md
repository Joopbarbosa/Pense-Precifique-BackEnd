### Endpoint:

```
POST /lotes-compra
```

```java
@RestController
@RequestMapping("/lotes-compra")
@RequiredArgsConstructor
public class LoteCompraController {

    private final LoteCompraService loteCompraService;

    @PostMapping
    public ResponseEntity<ImpactoAgregadoResponse> registrar(
            @Valid @RequestBody RegistrarLoteCompraRequest request,
            @AuthenticationPrincipal UserDetails userDetails) {
        UUID usuarioId = extrairUsuarioId(userDetails);
        return ResponseEntity.status(201).body(loteCompraService.registrarLote(request, usuarioId));
    }
}
```

Reutilize o mesmo padrão de extração de `usuarioId` já adotado nos outros controllers.

Compile ao final:
```bash
./mvnw compile -q
```
