# P-023 — Front: conectar FormInsumoPage (cadastrar/editar)

**Épico:** Épico 3 — Insumos
**Camada:** front
**Depende de:** P-022 (insumoService já criado)
**Modelo recomendado:** Sonnet

---

## Contexto para o Claude Code

A tela de formulário de insumo é usada tanto para cadastro (sem `id` na rota) quanto para edição (com `id` na rota). O `insumoService` já foi criado no P-022.

---

## Prompt

Cole este prompt no Claude Code:

---

Conecte `FormInsumoPage` (ou equivalente em `src/pages/insumos/`) aos endpoints reais de cadastro e edição de insumo.

**Leia o CLAUDE.md antes de começar. Leia o conteúdo atual da tela antes de editar.**

### Comportamento esperado:

**Modo cadastro** (rota sem `id`, ex: `/insumos/novo`):
- Formulário em branco
- Submit chama `insumoService.cadastrar(data)`
- Sucesso: redireciona para `/insumos` com toast "Insumo cadastrado com sucesso"

**Modo edição** (rota com `id`, ex: `/insumos/:id/editar`):
- Ao montar: chama `insumoService.buscarPorId(id)` e popula os campos com os dados existentes
- Submit chama `insumoService.editar(id, data)`
- Sucesso: redireciona para `/insumos/:id` (detalhe) com toast "Insumo atualizado com sucesso"

### Tratamento de erros:
- Erro `400` com `fieldErrors`: exibir mensagem por campo (ex: "Já existe um insumo com este nome e marca.")
- Erro genérico: exibir `error.response.data.message` em toast ou banner
- Estado de loading durante submit

### Campos do formulário (baseado em `InsumoRequest`):
- `nome` — obrigatório
- `marca` — opcional
- `unidadeMedida` — obrigatório
- `estoqueAtual` — numérico, opcional (default 0)
- `estoqueMinimo` — numérico, opcional

### Convenções:
- Não altere layout/estilos
- Reutilize padrão de formulário já existente no projeto
- `custoUnitario` **não é campo editável** — é calculado automaticamente nas compras; se a tela tiver esse campo visível, deixe-o como somente leitura

---

## Checklist de validação

- [ ] Modo cadastro: submit cria insumo e redireciona para `/insumos`
- [ ] Modo edição: tela carrega dados existentes ao montar
- [ ] Modo edição: submit atualiza e redireciona para o detalhe
- [ ] Erro de unicidade (`"Já existe um insumo com este nome e marca."`) exibido corretamente
- [ ] `custoUnitario` não é editável pelo usuário
- [ ] F5 no modo edição mantém os dados (vêm do backend)
