## Contexto para o Claude Code

**RN-037 — Cancelamento de produção:**
- Menu ⋮ disponível apenas na **lista** de produções, não no detalhe (Cenário 84)
- Opção "Cancelar produção" visível apenas para produções com `status = ATIVA` (Cenário 83)
- Modal de confirmação com resumo + observação obrigatória mín. 50 chars (Cenário 82)
- Após cancelar: produção exibida com indicador visual de status CANCELADA

**Cenários BDD:**
```gherkin
Cenário 82: botão desabilitado enquanto observação < 50 chars
Cenário 83: menu ⋮ de produção CANCELADA não exibe "Cancelar produção"
Cenário 84: menu ⋮ apenas na lista, não no detalhe
```

**Endpoint:** `POST /producoes/{id}/cancelar`

## Prompt

Cole este prompt no Claude Code:

---

Adicione o menu de ações (⋮) com "Cancelar produção" à lista de produções em `RegistroProducaoPage`.

**Leia o CLAUDE.md antes de começar. Leia o conteúdo atual da tela antes de editar.**

### 1. Adicionar ao `producaoService.ts`:

```ts
cancelar: async (id: string, observacao: string): Promise<ProducaoDetalheResponse> => {
  const response = await api.post(`/producoes/${id}/cancelar`, { observacao });
  return response.data;
},
```

### 2. Menu ⋮ na lista de produções:

- Exibir menu ⋮ em cada linha da lista
- Para produção com `status = 'ATIVA'`: exibir opção "Cancelar produção"
- Para produção com `status = 'CANCELADA'`: menu ⋮ não exibe "Cancelar produção" (pode exibir "Ver detalhe" se já existir na tela)
- **Não duplicar** o menu no detalhe da produção (Cenário 84)

### 3. Modal de cancelamento:

- Exibe resumo: nome do produto, quantidade, data da produção
- Campo de observação obrigatório com contador de caracteres
- Botão "Confirmar cancelamento" **desabilitado** enquanto `observacao.length < 50`
- Aviso: "Esta ação reverterá o estoque e não poderá ser desfeita"
- Submit: `producaoService.cancelar(id, observacao)`
- Sucesso: fecha modal, atualiza status da produção na lista para CANCELADA com indicador visual
- Erro: exibe `error.response.data.message`

### 4. Indicador visual de status na lista:

- ATIVA: badge verde (ou sem badge, dependendo do design atual)
- CANCELADA: badge vermelho ou texto riscado — verifique o padrão de badges já usado no projeto

### Convenções:
- Nenhum container ancestral do modal pode ter `overflow: hidden`
- Não altere layout/estilos existentes
- Reutilize componente de modal já existente no projeto

**Após conectar, compile e corrija todos os erros de TypeScript antes de commitar:**
```bash
npm run build 2>&1 | grep -E "error TS" | head -20
```
