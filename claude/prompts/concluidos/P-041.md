Crie a entidade JPA e repository para `Cliente` no backend Spring Boot.

**Leia o CLAUDE.md e o arquivo `src/main/resources/db/migration/V1__initial_schema.sql` antes de começar — confirme os nomes exatos das colunas da tabela `clientes` antes de mapear qualquer campo.**

### Entity: `Cliente` (em `domain/entity/`)

Campos:
- `id` UUID PK
- `usuario` → `@ManyToOne(fetch = LAZY)` para `Usuario`
- `nome` String NOT NULL
- `email` String nullable
- `whatsapp` String nullable
- `endereco` String nullable
- `observacoes` String nullable
- `ativa` boolean default true
- `deletedAt` LocalDateTime nullable
- `createdAt` LocalDateTime → `@CreationTimestamp`
- `updatedAt` LocalDateTime → `@UpdateTimestamp`

Use `@Column(name="...")` explicitamente em todos os campos para garantir alinhamento com o schema.

### Repository: `ClienteRepository` (em `domain/repository/`)

```java
public interface ClienteRepository extends JpaRepository<Cliente, UUID> {

    Page<Cliente> findByUsuarioIdAndDeletedAtIsNull(UUID usuarioId, Pageable pageable);

    Optional<Cliente> findByIdAndUsuarioIdAndDeletedAtIsNull(UUID id, UUID usuarioId);

    // Busca por nome (case-insensitive) para filtro na listagem
    Page<Cliente> findByUsuarioIdAndNomeContainingIgnoreCaseAndDeletedAtIsNull(
        UUID usuarioId, String nome, Pageable pageable);
}
```

Compile ao final:
```bash
./mvnw compile -q
```
