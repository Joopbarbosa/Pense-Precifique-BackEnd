## Contexto para o Claude Code

**Modelo de Produto (v4):** todo item cadastrado pertence a um dos 3 tipos:

| Tipo | Descrição | Preço de venda |
|------|-----------|----------------|
| PRODUTO | Item final vendável | obrigatório |
| PRODUTO_BASE | Componente usado em fichas técnicas | não tem |
| CUSTOMIZACAO | Extra opcional no orçamento | obrigatório |

**Constraint:** `preco_venda` é obrigatório quando `tipo = PRODUTO` ou `tipo = CUSTOMIZACAO`. `PRODUTO_BASE` nunca tem `preco_venda`.

**FichaTecnicaItem:** cada item da ficha técnica referencia um `Insumo` OU um `Produto` do tipo `PRODUTO_BASE`, com quantidade. O `preco_custo` do produto é calculado somando `(quantidade × custo_unitario)` de cada componente da ficha.

**MovimentacaoProduto:** mesma estrutura de `MovimentacaoInsumo`, com motivos diferentes.

### 1. Enum: `TipoProduto` (em `domain/enums/`)

```java
public enum TipoProduto {
    PRODUTO, PRODUTO_BASE, CUSTOMIZACAO
}
```

### 2. Enums de Movimentação de Produto (em `domain/enums/`)

```java
public enum TipoMovimentacaoProduto { ENTRADA, SAIDA }

public enum MotivoMovimentacaoProduto {
    PRODUCAO, ORCAMENTO, PERDA, AVARIA, USO_EXTRA, CORRECAO, OUTRO, ESTORNO_PRODUCAO
}
```

### 3. Entity: `Produto` (em `domain/entity/`)

Campos:
- `id` UUID PK
- `usuario` → `@ManyToOne(fetch = LAZY)` para `Usuario`
- `nome` String NOT NULL
- `tipo` → `TipoProduto` (`@Enumerated(EnumType.STRING)`) NOT NULL
- `descricao` String nullable
- `tempoProducao` Integer NOT NULL (em minutos)
- `foto` String nullable (URL)
- `precoVenda` BigDecimal nullable (obrigatório apenas para PRODUTO e CUSTOMIZACAO — validado no Service)
- `precoCusto` BigDecimal default 0 (calculado pela ficha técnica)
- `estoqueAtual` BigDecimal default 0
- `estoqueMinimo` BigDecimal nullable
- `ativo` boolean default true
- `deletedAt` LocalDateTime nullable
- `createdAt` LocalDateTime → `@CreationTimestamp`
- `updatedAt` LocalDateTime → `@UpdateTimestamp`

### 4. Entity: `FichaTecnicaItem` (em `domain/entity/`)

Campos:
- `id` UUID PK
- `produto` → `@ManyToOne(fetch = LAZY)` para `Produto` (o produto dono da ficha)
- `insumo` → `@ManyToOne(fetch = LAZY)` para `Insumo` nullable
- `produtoBase` → `@ManyToOne(fetch = LAZY)` para `Produto` nullable (apenas tipo PRODUTO_BASE)
- `quantidade` BigDecimal NOT NULL
- `createdAt` LocalDateTime → `@CreationTimestamp`

> Exatamente um de `insumo` ou `produtoBase` deve ser não-nulo — validado no Service.

### 5. Entity: `MovimentacaoProduto` (em `domain/entity/`)

Campos:
- `id` UUID PK
- `produto` → `@ManyToOne(fetch = LAZY)` para `Produto`
- `tipo` → `TipoMovimentacaoProduto` (`@Enumerated(EnumType.STRING)`)
- `motivo` → `MotivoMovimentacaoProduto` (`@Enumerated(EnumType.STRING)`)
- `quantidade` BigDecimal NOT NULL
- `observacao` String nullable
- `referenciaId` UUID nullable
- `referenciaTipo` String nullable
- `estornada` boolean default false
- `createdAt` LocalDateTime → `@CreationTimestamp`

Sem `updatedAt` — movimentações são imutáveis.

### 6. Repositories

```java
// ProdutoRepository
public interface ProdutoRepository extends JpaRepository<Produto, UUID> {
    Page<Produto> findByUsuarioIdAndDeletedAtIsNull(UUID usuarioId, Pageable pageable);
    Page<Produto> findByUsuarioIdAndTipoAndDeletedAtIsNull(UUID usuarioId, TipoProduto tipo, Pageable pageable);
    Optional<Produto> findByIdAndUsuarioIdAndDeletedAtIsNull(UUID id, UUID usuarioId);
    List<Produto> findByUsuarioIdAndTipoAndDeletedAtIsNull(UUID usuarioId, TipoProduto tipo);
}

// FichaTecnicaItemRepository
public interface FichaTecnicaItemRepository extends JpaRepository<FichaTecnicaItem, UUID> {
    List<FichaTecnicaItem> findByProdutoId(UUID produtoId);
    void deleteByProdutoId(UUID produtoId);
}

// MovimentacaoProdutoRepository
public interface MovimentacaoProdutoRepository extends JpaRepository<MovimentacaoProduto, UUID> {
    Page<MovimentacaoProduto> findByProdutoIdOrderByCreatedAtDesc(UUID produtoId, Pageable pageable);
}
```
