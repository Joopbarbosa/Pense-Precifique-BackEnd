# P-024 — Front: conectar DetalheInsumoPage + modal de baixa manual (RN-035)

**Épico:** Épico 3 — Insumos
**Camada:** front
**Depende de:** P-022, P-023
**Modelo recomendado:** Sonnet

## Contexto para o Claude Code

**RN-035:** ao registrar baixa manual, independentemente do motivo (Perda, Avaria, Uso extra, Correção de estoque, Outro), o campo `observacao` é obrigatório e deve ter no mínimo 50 caracteres. O botão de confirmar fica desabilitado enquanto a observação tiver menos de 50 caracteres.

**RN-034:** histórico de movimentações paginado, 20 por vez, com "Carregar mais".

**Errata v6:** não há botão de compra individual nesta tela. Compras são feitas via modal de lote na ListaInsumosPage (P-029).

**Cenário BDD (Cenário 77):**
```gherkin
Dado que a artesã está no modal de baixa manual
Quando seleciona qualquer motivo
Então o campo Observação é obrigatório com contador de caracteres
E o botão "Registrar baixa" fica desabilitado com menos de 50 chars
Quando escreve observação com 50+ chars → botão é habilitado
E ao confirmar, observação aparece no histórico
```

**Endpoints:**
- `GET /insumos/:id` → dados do insumo
- `POST /insumos/:id/baixa-manual` → registrar baixa
- `GET /insumos/:id/movimentacoes?page=0&size=20` → histórico paginado

## Prompt

Cole este prompt no Claude Code:

---

Conecte `DetalheInsumoPage` (ou equivalente em `src/pages/insumos/`) à API real.

**Leia o CLAUDE.md antes de começar. Leia o conteúdo atual da tela antes de editar.**

### 1. Adicionar ao `insumoService.ts`:

```ts
baixaManual: async (id: string, data: BaixaManualInsumoRequest): Promise<MovimentacaoInsumoResponse> => {
  const response = await api.post(`/insumos/${id}/baixa-manual`, data);
  return response.data;
},

listarMovimentacoes: async (id: string, page: number, size = 20): Promise<PageResponse<MovimentacaoInsumoResponse>> => {
  const response = await api.get(`/insumos/${id}/movimentacoes`, { params: { page, size } });
  return response.data;
},
```

Adicionar também aos tipos em `src/types/insumo.ts`:

```ts
export interface BaixaManualInsumoRequest {
  quantidade: number;
  motivo: 'BAIXA_MANUAL';
  observacao: string; // mín. 50 chars
}

export interface MovimentacaoInsumoResponse {
  id: string;
  tipo: 'ENTRADA' | 'SAIDA';
  motivo: string;
  quantidade: number;
  observacao?: string;
  referenciaId?: string;
  referenciaTipo?: string;
  estornada: boolean;
  createdAt: string;
}
```

### 2. Conectar `DetalheInsumoPage`:

- Ao montar: carrega dados do insumo via `insumoService.buscarPorId(id)` e histórico via `listarMovimentacoes(id, 0)`
- Histórico paginado: botão "Carregar mais" acumula movimentações (não substitui)
- **Movimentações com `estornada = true`** devem ser exibidas com estilo visual riscado (ex: `text-decoration: line-through` ou classe CSS equivalente já usada no projeto)

### 3. Modal de baixa manual:

- Campos: `quantidade` (numérico), `motivo` (select: Perda, Avaria, Uso extra, Correção de estoque, Outro), `observacao` (textarea)
- Contador de caracteres visível na `observacao`
- Botão "Registrar baixa" **desabilitado** enquanto `observacao.length < 50`
- Submit: chama `insumoService.baixaManual(id, { quantidade, motivo: 'BAIXA_MANUAL', observacao })`
- Sucesso: fecha modal, atualiza `estoqueAtual` exibido e recarrega histórico (ou adiciona a nova movimentação no topo da lista)
- Erro: exibe `error.response.data.message`

### Restrições:
- **Sem botão de compra individual** nesta tela (errata v6)
- Nenhum container ancestral do modal pode ter `overflow: hidden`
- Não altere layout/estilos
