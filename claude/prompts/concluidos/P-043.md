### Métodos obrigatórios:

```java
@Component
public class ClienteMapper {

    // Cliente → ClienteResponse
    public ClienteResponse toResponse(Cliente cliente);

    // ClienteRequest → Cliente (novo cadastro)
    public Cliente toEntity(ClienteRequest request, Usuario usuario);

    // Atualiza campos de um Cliente existente
    public void updateEntity(ClienteRequest request, Cliente cliente);

    // List<Cliente> → List<ClienteResponse>
    public List<ClienteResponse> toResponseList(List<Cliente> clientes);
}
```

### Regras de mapeamento:

- `toEntity`: `ativa = true`, `deletedAt = null`
- `updateEntity`: atualiza `nome`, `email`, `whatsapp`, `endereco`, `observacoes` — **não** toca em `ativa` nem `deletedAt`

Compile ao final:
```bash
./mvnw compile -q
```
