# P-039 — Front: conectar CadastrarProdutoPage e EditarProdutoPage (incl. ficha técnica)

**Épico:** Épico 4 — Produtos
**Camada:** front
**Depende de:** P-038 (produtoService, tipos criados)
**Modelo recomendado:** Sonnet

---

## Contexto para o Claude Code

O formulário de produto é a tela mais complexa do Épico 4 — inclui a ficha técnica com buscador de insumos e produtos base, além da constraint de `precoVenda` por tipo.

---

## Prompt

Cole este prompt no Claude Code:

---

Conecte `CadastrarProdutoPage` e `EditarProdutoPage` (ou equivalentes em `src/pages/produtos/`) às APIs reais.

**Leia o CLAUDE.md antes de começar. Leia o conteúdo atual de ambas as telas antes de editar.**

### 1. Adicionar ao `produtoService.ts`:

```ts
// Busca insumos para o buscador da ficha técnica
buscarInsumos: async (busca: string) => {
  const response = await api.get('/insumos', { params: { page: 0, size: 20, busca, sort: 'nome' } });
  return response.data.content;
},

// Busca produtos base para a ficha técnica
buscarProdutosBase: async (busca: string) => {
  const response = await api.get('/produtos', { params: { page: 0, size: 20, tipo: 'PRODUTO_BASE', busca, sort: 'nome' } });
  return response.data.content;
},
```

### 2. Modo cadastro (`CadastrarProdutoPage`):

- Formulário em branco com `fichaTecnica: []`
- Submit chama `produtoService.cadastrar(data)`
- Sucesso: redireciona para `/produtos` com toast "Produto cadastrado com sucesso"

### 3. Modo edição (`EditarProdutoPage`):

- Ao montar: `produtoService.buscarPorId(id)` → popula campos incluindo ficha técnica
- Submit chama `produtoService.editar(id, data)`
- Sucesso: redireciona para `/produtos/:id` com toast "Produto atualizado com sucesso"

### 4. Ficha técnica (componente de lista de itens):

- Cada item tem: tipo de componente (Insumo ou Produto Base), campo de busca, quantidade
- Buscador de insumos: `produtoService.buscarInsumos(busca)` com debounce 300ms
- Buscador de produtos base: `produtoService.buscarProdutosBase(busca)` com debounce 300ms
- Adicionar item: append à lista `fichaTecnica`
- Remover item: remove da lista
- `custoTotal` de cada item exibido como leitura: `quantidade × custoUnitario` do componente selecionado
- `precoCusto` total do produto exibido como soma dos `custoTotal` dos itens (somente leitura)

### 5. Constraint de precoVenda no formulário:

- Se `tipo === 'PRODUTO_BASE'`: ocultar ou desabilitar o campo `precoVenda`
- Se `tipo === 'PRODUTO'` ou `'CUSTOMIZACAO'`: exibir campo `precoVenda` como obrigatório

### 6. Tratamento de erros:

- `400` com `fieldErrors`: exibir por campo
- `400` com `message` (ex: "Produto Base não pode ter preço de venda."): exibir em toast/banner
- Loading durante submit

### Convenções:
- Não altere layout/estilos
- Reutilize componentes de busca/autocomplete já existentes no projeto
