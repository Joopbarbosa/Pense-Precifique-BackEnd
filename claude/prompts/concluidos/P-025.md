## Contexto para o Claude Code

**RN-036:** compras de insumos são registradas exclusivamente via lote. Cada lote agrupa N movimentações de entrada (uma por insumo), todas vinculadas pelo mesmo `lote_compra.id` via `referencia_id` nas movimentações.

**Entidade LoteCompra** (tabela `lotes_compra`):

| Campo | Tipo | Observação |
|-------|------|------------|
| id | UUID | PK — usado como `referencia_id` nas movimentações |
| usuario_id | UUID | FK usuarios |
| data_compra | datetime | data informada pelo usuário |
| created_at | datetime | |

Sem `updated_at` e sem `deleted_at` — lotes são imutáveis após criados.

### 1. Entity: `LoteCompra` (em `domain/entity/`)

```java
@Entity
@Table(name = "lotes_compra")
public class LoteCompra {

    @Id
    private UUID id;

    @ManyToOne(fetch = FetchType.LAZY)
    @JoinColumn(name = "usuario_id", nullable = false)
    private Usuario usuario;

    @Column(name = "data_compra", nullable = false)
    private LocalDateTime dataCompra;

    @CreationTimestamp
    @Column(name = "created_at", updatable = false)
    private LocalDateTime createdAt;

    @PrePersist
    public void prePersist() {
        if (this.id == null) this.id = UUID.randomUUID();
    }
}
```

### 2. Repository: `LoteCompraRepository` (em `domain/repository/`)

```java
public interface LoteCompraRepository extends JpaRepository<LoteCompra, UUID> {

    // Buscar lote por id garantindo que pertence ao usuário
    Optional<LoteCompra> findByIdAndUsuarioId(UUID id, UUID usuarioId);
}
```

Compile ao final:
```bash
./mvnw compile -q
```
