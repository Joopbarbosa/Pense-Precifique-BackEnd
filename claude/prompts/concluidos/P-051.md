### Endpoints:

```
GET  /producoes                          → listar (paginado, mais recente primeiro)
GET  /producoes/{id}                     → detalhe
POST /producoes                          → lançar produção
GET  /producoes/preview?produtoId=&quantidade=  → preview de insumos que serão consumidos
```

### Implementação:

```java
@RestController
@RequestMapping("/producoes")
@RequiredArgsConstructor
public class ProducaoController {

    private final ProducaoService producaoService;

    @GetMapping
    public ResponseEntity<Page<ProducaoResponse>> listar(
            @AuthenticationPrincipal UserDetails userDetails,
            @PageableDefault(size = 20) Pageable pageable) {
        UUID usuarioId = extrairUsuarioId(userDetails);
        return ResponseEntity.ok(producaoService.listar(usuarioId, pageable));
    }

    @GetMapping("/{id}")
    public ResponseEntity<ProducaoDetalheResponse> buscar(
            @PathVariable UUID id,
            @AuthenticationPrincipal UserDetails userDetails) {
        UUID usuarioId = extrairUsuarioId(userDetails);
        return ResponseEntity.ok(producaoService.buscarPorId(id, usuarioId));
    }

    @PostMapping
    public ResponseEntity<ProducaoDetalheResponse> lancar(
            @Valid @RequestBody LancarProducaoRequest request,
            @AuthenticationPrincipal UserDetails userDetails) {
        UUID usuarioId = extrairUsuarioId(userDetails);
        return ResponseEntity.status(201).body(producaoService.lancar(request, usuarioId));
    }

    @GetMapping("/preview")
    public ResponseEntity<List<InsumoConsumidoResponse>> preview(
            @RequestParam UUID produtoId,
            @RequestParam BigDecimal quantidade,
            @AuthenticationPrincipal UserDetails userDetails) {
        UUID usuarioId = extrairUsuarioId(userDetails);
        return ResponseEntity.ok(producaoService.previewInsumosConsumidos(produtoId, quantidade, usuarioId));
    }
}
```

Reutilize o mesmo padrão de extração de `usuarioId` dos controllers anteriores.

Compile ao final:
```bash
./mvnw compile -q
```
