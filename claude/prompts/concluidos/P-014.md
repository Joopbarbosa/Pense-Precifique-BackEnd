### 1. `src/types/empresa.ts` (novo arquivo)

```ts
export interface EmpresaRequest {
  nome: string;
  email?: string;
  whatsapp?: string;
  endereco?: string;
  logoUrl?: string;
}

export interface EmpresaResponse {
  id: string;
  nome: string;
  email?: string;
  whatsapp?: string;
  endereco?: string;
  logoUrl?: string;
  createdAt: string;
  updatedAt: string;
}

export interface ConfiguracaoRequest {
  valorHora: number;
  margemPadrao: number;
}

export interface ConfiguracaoResponse {
  id: string | null;
  valorHora: number;
  margemPadrao: number;
  updatedAt: string | null;
}
```

### 2. `src/services/empresaService.ts` (novo arquivo)

```ts
import api from './api';
import type { EmpresaRequest, EmpresaResponse, ConfiguracaoRequest, ConfiguracaoResponse } from '../types/empresa';

export const empresaService = {
  getEmpresa: async (): Promise<EmpresaResponse | null> => {
    try {
      const response = await api.get<EmpresaResponse>('/empresa');
      return response.data;
    } catch (error: any) {
      if (error.response?.status === 404) {
        return null; // ainda não configurado
      }
      throw error;
    }
  },
  upsertEmpresa: async (data: EmpresaRequest): Promise<EmpresaResponse> => {
    const response = await api.put<EmpresaResponse>('/empresa', data);
    return response.data;
  },
  getConfiguracao: async (): Promise<ConfiguracaoResponse> => {
    const response = await api.get<ConfiguracaoResponse>('/configuracoes/precificacao');
    return response.data;
  },
  upsertConfiguracao: async (data: ConfiguracaoRequest): Promise<ConfiguracaoResponse> => {
    const response = await api.put<ConfiguracaoResponse>('/configuracoes/precificacao', data);
    return response.data;
  },
};
```

### 3. Conectar `OnboardingPage.tsx`

- Ao montar a página (opcional — pode pular se a tela for sempre "em branco" para
  preenchimento inicial): pode chamar `empresaService.getEmpresa()` para verificar se
  já existe configuração; se já existir (`!= null`), redirecionar direto para
  `/dashboard` (evita reexibir onboarding para quem já completou)
- No submit do formulário:
  - Chame `empresaService.upsertEmpresa({ nome, email, whatsapp, endereco })` com os
    campos preenchidos na tela
  - Se a tela também tiver campos de valor/hora e margem (verifique o conteúdo real da
    tela), chame também `empresaService.upsertConfiguracao({ valorHora, margemPadrao })`
  - Em caso de sucesso: redirecione para `/dashboard`
  - Em caso de erro: exiba `error.response.data.message` (e `fieldErrors`, se houver)
  - Estado de loading durante a chamada

### 4. Conectar `ConfiguracoesPage.tsx`

- Ao montar a página: chame `empresaService.getEmpresa()` e
  `empresaService.getConfiguracao()` em paralelo (ex: `Promise.all` ou dois `useEffect`)
  para popular os campos das abas "Perfil da empresa" e "Precificação"
  - Se `getEmpresa()` retornar `null` (404 → ainda não configurado), deixe os campos
    vazios/com placeholder (não trate como erro — é um estado válido, ex: usuário pulou
    o onboarding de alguma forma)
  - Mostre um estado de loading enquanto os dados carregam
- No botão "Salvar alterações" (ou equivalente por aba, se a tela salvar cada aba
  separadamente):
  - Aba "Precificação": chama `empresaService.upsertConfiguracao({ valorHora,
    margemPadrao })`
  - Aba "Perfil da empresa": chama `empresaService.upsertEmpresa({ nome, email,
    whatsapp, endereco, logoUrl })`
  - Em caso de sucesso: feedback visual (toast "Salvo com sucesso" ou o indicador
    "Tudo salvo" já visto na tela)
  - Em caso de erro: exiba a mensagem do backend
