Adicione o endpoint de histórico de movimentações de produto ao `ProdutoService` e `ProdutoController`.

**Leia o CLAUDE.md antes de começar.**

### 1. Adicionar ao `ProdutoService`:

```java
public Page<MovimentacaoProdutoResponse> listarMovimentacoes(UUID produtoId, UUID usuarioId, Pageable pageable);
```

**Lógica:**
1. Verificar que o produto existe e pertence ao usuário
2. Buscar via `movimentacaoProdutoRepository.findByProdutoIdOrderByCreatedAtDesc(produtoId, pageable)`
3. Mapear para `Page<MovimentacaoProdutoResponse>`

### 2. Adicionar ao `ProdutoController`:

```java
@GetMapping("/{id}/movimentacoes")
public ResponseEntity<Page<MovimentacaoProdutoResponse>> listarMovimentacoes(
        @PathVariable UUID id,
        @AuthenticationPrincipal UserDetails userDetails,
        @PageableDefault(size = 20) Pageable pageable) {
    UUID usuarioId = extrairUsuarioId(userDetails);
    return ResponseEntity.ok(produtoService.listarMovimentacoes(id, usuarioId, pageable));
}
```

Compile ao final:
```bash
./mvnw compile -q
```
