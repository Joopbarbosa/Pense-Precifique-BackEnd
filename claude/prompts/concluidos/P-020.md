## Contexto para o Claude Code

**RN-035:** ao registrar baixa manual de insumo, independentemente do motivo (PERDA, AVARIA, USO_EXTRA, CORRECAO, OUTRO), o campo `observacao` é obrigatório e deve ter no mínimo 50 caracteres.

**Cenário BDD de aceite (Cenário 77):**
```gherkin
Dado que a artesã está no modal de baixa manual do insumo
Quando ela seleciona qualquer motivo (ex: "Perda")
E informa quantidade
Então o campo Observação é obrigatório com mínimo 50 caracteres
E ao confirmar, a observação aparece no histórico de movimentações
```

## Prompt

Adicione o fluxo de baixa manual ao `InsumoService` e exponha o endpoint no `InsumoController`.

**Leia o CLAUDE.md antes de começar.**

### 1. Adicionar ao `InsumoService`:

```java
// Baixa manual: subtrai estoque e registra movimentação
public MovimentacaoInsumoResponse baixaManual(UUID insumoId, BaixaManualInsumoRequest request, UUID usuarioId);
```

**Lógica:**
1. Buscar o insumo pelo `insumoId` e `usuarioId` (lançar `ResourceNotFoundException` se não encontrado)
2. Verificar se `estoqueAtual >= request.getQuantidade()` — se não, lançar `BusinessException("Estoque insuficiente para realizar a baixa.")`
3. Subtrair `request.getQuantidade()` do `estoqueAtual` do insumo
4. Criar `MovimentacaoInsumo`:
   - `tipo = SAIDA`
   - `motivo = BAIXA_MANUAL`
   - `quantidade = request.getQuantidade()`
   - `observacao = request.getObservacao()`
   - `estornada = false`
   - `referenciaId = null`
   - `referenciaTipo = null`
5. Salvar insumo atualizado e movimentação
6. Retornar `MovimentacaoInsumoResponse`

### 2. Adicionar ao `InsumoController`:

```
POST /insumos/{id}/baixa-manual
```

```java
@PostMapping("/{id}/baixa-manual")
public ResponseEntity<MovimentacaoInsumoResponse> baixaManual(
        @PathVariable UUID id,
        @Valid @RequestBody BaixaManualInsumoRequest request,
        @AuthenticationPrincipal UserDetails userDetails) {
    UUID usuarioId = extrairUsuarioId(userDetails);
    return ResponseEntity.status(201).body(insumoService.baixaManual(id, request, usuarioId));
}
```

> A validação de mínimo 50 caracteres na `observacao` já está no `BaixaManualInsumoRequest` via `@Size(min = 50)` (criado no P-016). O `@Valid` no controller garante que essa validação seja aplicada antes de chegar ao service.

Compile ao final:
```bash
./mvnw compile -q
```
