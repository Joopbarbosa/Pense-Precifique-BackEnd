## Contexto para o Claude Code

**RN-035:** baixa manual exige observação obrigatória com mínimo 50 caracteres para qualquer motivo.
**RN-034:** histórico paginado com "Carregar mais".
**Cenário 78:** botão desabilitado enquanto observação < 50 chars.

**Endpoints:**
- `GET /produtos/:id` → detalhe com ficha técnica
- `POST /produtos/:id/baixa-manual` → registrar baixa
- `GET /produtos/:id/movimentacoes?page=0&size=20` → histórico paginado

## Prompt

Cole este prompt no Claude Code:

---

Conecte `DetalheProdutoPage` (ou equivalente em `src/pages/produtos/`) à API real.

**Leia o CLAUDE.md antes de começar. Leia o conteúdo atual da tela antes de editar.**

### 1. Adicionar ao `produtoService.ts`:

```ts
baixaManual: async (id: string, data: BaixaManualProdutoRequest): Promise<MovimentacaoProdutoResponse> => {
  const response = await api.post(`/produtos/${id}/baixa-manual`, data);
  return response.data;
},

listarMovimentacoes: async (id: string, page: number, size = 20): Promise<PageResponse<MovimentacaoProdutoResponse>> => {
  const response = await api.get(`/produtos/${id}/movimentacoes`, { params: { page, size } });
  return response.data;
},
```

Adicionar aos tipos em `src/types/produto.ts`:

```ts
export interface BaixaManualProdutoRequest {
  quantidade: number;
  motivo: 'PERDA' | 'AVARIA' | 'USO_EXTRA' | 'CORRECAO' | 'OUTRO';
  observacao: string; // mín. 50 chars
}

export interface MovimentacaoProdutoResponse {
  id: string;
  tipo: 'ENTRADA' | 'SAIDA';
  motivo: string;
  quantidade: number;
  observacao?: string;
  referenciaId?: string;
  referenciaTipo?: string;
  estornada: boolean;
  createdAt: string;
}
```

### 2. Conectar `DetalheProdutoPage`:

- Ao montar: carrega `produtoService.buscarPorId(id)` e `produtoService.listarMovimentacoes(id, 0)`
- Exibe ficha técnica com `custoTotal` por item e `precoCusto` total
- Histórico paginado com "Carregar mais" (acumula)
- **Movimentações com `estornada = true`** exibidas com estilo riscado
- Badge de tipo usando `tipoProdutoBadge` de `src/utils/badges.ts`

### 3. Modal de baixa manual:

- Campos: `quantidade` (numérico), `motivo` (select: Perda, Avaria, Uso extra, Correção de estoque, Outro), `observacao` (textarea)
- Contador de caracteres visível
- Botão "Registrar baixa" **desabilitado** enquanto `observacao.length < 50` (Cenário 78)
- Submit: `produtoService.baixaManual(id, { quantidade, motivo, observacao })`
- Sucesso: fecha modal, atualiza `estoqueAtual` exibido, recarrega histórico

### Convenções:
- Não altere layout/estilos
- Nenhum container ancestral do modal pode ter `overflow: hidden`
- Badge de tipo via `src/utils/badges.ts`
