Crie os DTOs de Produção em `src/main/java/com/penseprecifique/api/dto/`.

**Leia o CLAUDE.md antes de começar.**

### 1. `LancarProducaoRequest.java`

```java
public class LancarProducaoRequest {

    @NotNull(message = "O produto é obrigatório")
    private UUID produtoId;

    @NotNull(message = "A quantidade é obrigatória")
    @DecimalMin(value = "0.001", message = "A quantidade deve ser maior que zero")
    private BigDecimal quantidade;

    // Data opcional — default: agora
    private LocalDateTime dataProducao;
}
```

### 2. `CancelarProducaoRequest.java`

```java
public class CancelarProducaoRequest {

    @NotBlank(message = "A observação é obrigatória")
    @Size(min = 50, message = "A observação deve ter no mínimo 50 caracteres")
    private String observacao;
}
```

### 3. `InsumoConsumidoResponse.java`

```java
public class InsumoConsumidoResponse {
    private UUID insumoId;
    private String nomeInsumo;
    private String marca;
    private String unidadeMedida;
    private BigDecimal quantidade;
    private BigDecimal estoqueAntes;  // estoque antes da produção (informativo)
    private boolean estoqueInsuficiente; // true se estoque atual < quantidade necessária
}
```

### 4. `ProducaoResponse.java` (listagem)

```java
public class ProducaoResponse {
    private UUID id;
    private Integer numero;
    private UUID produtoId;
    private String nomeProduto;
    private TipoProduto tipoProduto;
    private BigDecimal quantidade;
    private LocalDateTime dataProducao;
    private StatusProducao status;
}
```

### 5. `ProducaoDetalheResponse.java`

```java
public class ProducaoDetalheResponse {
    private UUID id;
    private Integer numero;
    private UUID produtoId;
    private String nomeProduto;
    private TipoProduto tipoProduto;
    private BigDecimal quantidade;
    private LocalDateTime dataProducao;
    private StatusProducao status;
    private String observacaoCancelamento;
    private LocalDateTime dataCancelamento;
    private List<InsumoConsumidoResponse> insumosConsumidos;
}
```

Compile ao final:
```bash
./mvnw compile -q
```
