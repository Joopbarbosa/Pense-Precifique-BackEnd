## Contexto para o Claude Code

**RN-036:** ao confirmar um lote, o sistema recalcula o custo unitário de cada insumo e exibe um modal de impacto agregado listando produtos/customizações afetados e seus novos preços sugeridos.

O `ImpactoAgregadoResponse` representa esse modal — por ora retorna apenas os insumos atualizados com seus novos custos. A lógica de impacto em produtos será expandida no Épico 4.

## Prompt

Cole este prompt no Claude Code:

---

Crie os DTOs de compra em lote em `src/main/java/com/penseprecifique/api/dto/`.

**Leia o CLAUDE.md antes de começar.**

### 1. `ItemLoteCompraRequest.java` (item individual dentro do lote)

```java
public class ItemLoteCompraRequest {

    @NotNull(message = "O id do insumo é obrigatório")
    private UUID insumoId;

    @NotNull(message = "A quantidade comprada é obrigatória")
    @DecimalMin(value = "0.001", message = "A quantidade deve ser maior que zero")
    private BigDecimal quantidadeComprada;

    @NotNull(message = "O preço total pago é obrigatório")
    @DecimalMin(value = "0.01", message = "O preço total deve ser maior que zero")
    private BigDecimal precoTotalPago;
}
```

### 2. `RegistrarLoteCompraRequest.java`

```java
public class RegistrarLoteCompraRequest {

    // Data da compra informada pelo usuário (opcional — default: agora)
    private LocalDateTime dataCompra;

    @NotEmpty(message = "O lote deve conter pelo menos um insumo")
    @Valid
    private List<ItemLoteCompraRequest> itens;
}
```

### 3. `InsumoImpactoResponse.java` (item dentro do modal de impacto)

```java
public class InsumoImpactoResponse {
    private UUID insumoId;
    private String nomeInsumo;
    private String marca;
    private String unidadeMedida;
    private BigDecimal custoUnitarioAnterior;
    private BigDecimal custoUnitarioNovo;
    private BigDecimal quantidadeAdicionada;
}
```

### 4. `ImpactoAgregadoResponse.java`

```java
public class ImpactoAgregadoResponse {
    private UUID loteId;
    private LocalDateTime dataCompra;
    private List<InsumoImpactoResponse> insumosAtualizados;

    // Placeholder para épicos futuros — retorna lista vazia por ora
    private List<Object> produtosAfetados = new ArrayList<>();
}
```
